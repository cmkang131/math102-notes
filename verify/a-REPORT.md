# v6-extra-a 보고서 (브랜치 `v6x-claude-a`)

새 파일만 추가했습니다: `assets/v6-extra-a.js`, `demo-a.html`, `verify/` (기존 v6.js·v6.css 수정 없음).
레지스트리 이름 `series-converge`, `newton1d`, `newton2d`, `cobweb` 는 v6.js 의 `slider-plot`, `stepthrough` 와 겹치지 않습니다.

## 실제 API 확인 결과 (요청서와 다른 점)

| 항목 | 요청서 설명 | 실제 v6.js | 대응 |
|---|---|---|---|
| `V6.makeFn(src,names)` | 함수 반환 | 반환 함수는 **값 배열** 하나를 받음 `f([v1,v2])`. 문법 오류는 생성 시점에 `new Function`이 **throw** | `compile()` 래퍼에서 try/catch, 배열 호출로 감쌈 |
| makeFn 허용 함수 | abs … max | 같음. 단 `Math` 등 전역 접근이 막혀 있지 않음(진짜 샌드박스 아님) | 래퍼에서 문자·이름 화이트리스트 검사 후에만 makeFn 호출. `atan asin acos sinh cosh tanh` 는 추가 인자로 넘겨 지원 |
| `^` | 미지원 | JS에서 `^`는 XOR라 **오류 없이 틀린 값**이 나옴 | `^` 가 있으면 계산하지 않고 "pow(n,2)처럼 쓰세요" 메시지 |
| `V6.axes` | 축 그리기 | 여백·눈금 숫자 라벨이 없음 (격자 1/8 등분만) | 숫자 라벨이 필요해서 쓰지 않고, 같은 색(GRID/INK)으로 여백 있는 `frame()` 을 따로 작성 |
| `V6.canvas(el,h)` | 720×h | 같음 | 그대로 사용 |
| 잘못된 data-config JSON | — | boot 가 **조용히 건너뜀**(빈 칸) | 이 파일의 위젯 이름이면 boot 뒤에 한국어 안내 한 줄을 넣음 |
| 위젯 예외 | — | boot 가 영어 "widget error" 표시 | 각 위젯을 자체 try/catch 로 감싸 한국어 메시지 |
| 기존 페이지 사용 예 | "위젯 쓰는 HTML 하나 읽기" | **레포에 v6-widget 을 쓰는 페이지가 아직 없음** | demo-a.html 이 첫 사용 예. 폰트는 hw1/fonts 의 Noto Sans KR 을 데모 페이지 인라인 @font-face 로 연결 |

## 위젯별 기능과 수학 내용

### 1. `series-converge`
- 위 패널 a_n, 아래 패널 S_n (같은 n 축). 마지막 점(N)은 빨강. "보기"(급수/수열)에 해당하는 패널을 굵은 테두리로 강조.
- 프리셋: 기하(r 슬라이더 −1.5…1.5), 조화 1/n, 1/n², 교대 (−1)ⁿ⁺¹/n, n/(n+1) (기본: 수열 보기), p급수(p 슬라이더 0.5…3), 직접 입력.
- 점선(빨강): lim a_n, 그리고 수렴할 때의 합(1/(1−r), π²/6, ln 2, ζ(p)). 조화급수에는 비교 곡선 ln n + γ (회색 점선, "비교" 표기).
- 판정 문구: 일반항 판정(기하 |r|≥1, n/(n+1)), 적분판정(조화, 1/n², p급수), 교대급수판정 + 조건수렴(교대 조화).
- 오차 문구: 1/n² 와 p급수는 적분판정 꼬리 범위 `1/((p−1)(N+1)^(p−1)) < 합 − S_N < 1/((p−1)N^(p−1))`, 교대 조화는 `|ln2 − S_N| ≤ 1/(N+1)` 을 현재 N 의 수치로 표시.
- 직접 입력: 점선 없음, 문구는 "수치일 뿐 증명이 아니다"로 단정하지 않음. a_n 이 정의되지 않는 n 은 목록으로 알리고 그 뒤 부분합은 "정의 안 됨".
- |값| > 10⁹ 는 축 밖 ▲/▼ 로 클램프하고 "발산" 표기.

### 2. `newton1d`
- 단계 버튼: 반복마다 3단계 (x_k 표시 → 그래프 위 점 → 접선과 x축 교점 x_{k+1}). "한 반복", "끝까지"(애니메이션), "처음". `cfg.step` 으로 초기 단계 지정.
- 표: n, x_n(16자리), f(x_n), e_n = |x_n − r|, e_n/e_{n−1}, e_n/e_{n−1}². 단순근에서는 마지막 열이 C = |f''(r)/(2f'(r))| 로 모이는 것(√2: 0.354, cos x − x: 0.2208)이 보임.
- 프리셋: x²−2, cos x − x, x³−2x+2 (x₀=0 → 0,1,0,1… 2-주기, 실근 −1.7693), arctan x (x₀=1.5 발산; 임계값 |x₀| ≈ 1.3917 = 2x=(1+x²)arctan x 의 해), x²−2 (x₀=0.1, f'≈0 → x₁≈10.05), (x−1)² 중근(오차가 정확히 절반: 1차 수렴), 직접 입력(f' 비우면 중심차분).
- 멈춤 처리: |f'| < 10⁻¹² 이면 멈추고 "접선이 수평" 메시지(같이 f≈0 이면 "중근 근처 도달"), |x| > 10⁸ 이면 "발산", 아주 먼 x 에서 f'≈0 인 경우도 "발산"으로 분류. 2-주기는 자동 감지해 문구 표시. f''(r)=0 인 경우(arctan) "3차" 안내.
- 문구: "2차 수렴은 단순근(f'(r)≠0) 근처에서만, 중근이면 1차".

### 3. `newton2d`
- F = (F₁, F₂), J·Δ = −F 를 크라메르 공식으로 풂. 반복마다 3단계: 현재 점 → L₁ (F₁ 선형화 = 0) → L₂ 와 교점(= 다음 점).
- L_i 는 "곡선 F_i=0 의 접선이 아니라 F_i 의 1차 근사가 0이 되는 직선(점이 곡선 위일 때만 접선)" 이라고 명시.
- 곡선은 해석적 매개변수식으로만 그림(등고선 알고리즘 없음): 원 (2cos t, 2sin t), xy=1 두 가지 (±eᵗ, ±e⁻ᵗ), x²−y²=1 두 가지 (±cosh t, sinh t). x·y 같은 축척(원이 원으로 보임).
- 해 4개를 ○ 로 표시: (±√(2+√3), ±√(2−√3)) 등 / (±√2.5, ±√1.5).
- det J ≈ 0 (|det| < 10⁻¹²·‖J‖²): 멈추고 "두 직선이 평행 — 교점 없음/유일하지 않음" + 특이 집합(|x|=|y| 또는 x=0·y=0) 안내. det 가 작으면(‖J‖² 대비 10⁻³) "한 걸음이 매우 큼" 경고. 그림 밖 점은 문구로 좌표 표시.
- 그림 클릭 또는 x₀·y₀ 슬라이더로 시작점 변경. 표: n, x_n, y_n, |F|, det J, 가장 가까운 해까지 거리.

### 4. `cobweb`
- y=x(점선), y=g(x), 거미줄(마지막 선분 빨강), 고정점 ○, 오른쪽에 x_n 목록(최근 25개, 그림 밖이면 표시).
- 프리셋: cos x (모든 x₀ 수렴 이유: [−1,1] 에서 |sin x| ≤ sin 1 < 1), 로지스틱 r·x(1−x) (r 슬라이더 0…4, 기본 2.8), x/2+1, x² (반발 고정점 1), 직접 입력.
- 고정점마다 g'(x*) 와 판정: <1 국소 수축(부호로 진동/단조 접근), >1 반발, =1 판정 불가.
- 로지스틱 구간 문구: r<1, r=1, 1<r<3 (x*=1−1/r, g'(x*)=2−r), r=3, 3<r<1+√6≈3.449 (2-주기), 4-주기(…3.5441), 8·16…(…3.5699), 혼돈+주기 창(1+√8 ≈ 3.8284 의 3-주기 창), r=4.
- 장기 거동(수치 관찰, 20000회 후): 고정점/주기 p(≤64)/주기 없음/발산. 진폭이 아직 줄고 있으면 "느린 수렴"으로 표시해 r=3 을 2-주기로 오판하지 않음.
- 축소사상 연결 문구(닫힌 구간, g(I)⊂I, |g'|≤k<1 ⇒ 유일 고정점·수렴; 음함수정리 증명의 축소사상 논법과 같은 구조).

## 한계 · 불확실한 부분 (솔직하게)

- **수치 검증과 화면 확인은 모두 제가 직접 했습니다(자기 보고).** 헤드리스 Chromium 1종(데스크톱 폭 800px)에서만 렌더링했고, 실제 사이트 페이지에 넣어 보거나 모바일·Safari·Firefox 에서 확인하지는 않았습니다.
- **스크린샷은 시작 상태(cfg.step)만 찍었습니다.** "끝까지 ▶" 애니메이션 도중 화면, 슬라이더를 끄는 동안의 화면은 퍼징으로 예외만 확인했고 눈으로 보지는 않았습니다.
- 라벨 겹침은 데모 34개에서만 확인했습니다. 사용자가 x 범위나 식을 바꾸면 접선 라벨(x_k), 직선 라벨(L₁/L₂), 점 좌표 라벨이 곡선이나 서로 조금 겹칠 수 있습니다. newton2d 의 (1, 1.01) 라벨이 L₂ 직선에 살짝 걸리는 정도의 겹침은 남아 있습니다.
- **판정은 프리셋에서만 단정합니다.** 직접 입력한 급수는 수렴·발산을 판정하지 않습니다(의도한 동작). 직접 입력한 뉴턴의 "오차"는 100회 반복한 값을 참값 대신 쓴 추정치이고, 직접 입력한 g 의 고정점은 그림 범위 안에서만 수치로 찾습니다. 불연속 함수는 놓치거나 경계에서 틀릴 수 있습니다(tan 의 극은 걸러짐).
- cobweb 의 장기 거동은 **20000회 수치 관찰**입니다. 주기 64를 넘는 궤도나 분기점 바로 옆의 아주 느린 수렴은 "주기 없음"이나 "느린 수렴"으로 잘못 보일 수 있습니다. 화면에도 "수치 관찰일 뿐 증명은 아님"이라고 적어 두었습니다. 로지스틱 구간 문구는 r 로만 정하고, 3.5699 이상에서는 개별 r 의 창(window)을 맞히지 않습니다. 이 경우 수치 관찰 줄을 같이 보아야 합니다.
- 뉴턴 멈춤 기준(|f'| < 10⁻¹² 이면서 다음 걸음 > 10⁸, |x| > 10⁸ 이면 발산, 2-주기 감지)은 경험적 임계값입니다. 스케일이 아주 크거나 작은 f 에서는 판정 문구가 어색할 수 있습니다.
- `V6.makeFn` 은 진짜 샌드박스가 아닙니다. 위젯 입력창은 문자·이름 화이트리스트로 막았지만, data-config 에 들어가는 식은 페이지 작성자를 믿는다는 전제입니다. 거듭제곱 `**` 는 허용하고, `-2**2` 같은 JS 문법 오류는 "식을 해석할 수 없습니다"로 처리합니다.
- ζ(p)(p≠2)는 Euler–Maclaurin 수치값입니다. 화면에 "(수치 계산값)"이라고 표기하고, 독립 합과 문헌값으로 10⁻⁹ 이내인지 확인했습니다.
- "음함수정리 증명의 축소사상 논법과 같은 구조"라는 문구는 요청서를 따른 것입니다. Lax & Terrell 교재의 음함수정리 증명이 실제로 축소사상을 쓰는지는 교재를 직접 확인하지 못했습니다. 그래서 "축소사상으로 음함수정리를 증명할 때와 같은 구조"라고 일반적인 표현으로 적었습니다. 교재 증명 방식이 다르면 문구를 바꿔야 합니다.
- demo-a.html 은 Noto Sans KR 을 `hw1/fonts/` 에서 빌려 씁니다. 다른 페이지에 넣을 때는 그 페이지의 폰트 설정을 따릅니다. 캔버스 글꼴은 폰트 로드 뒤 한 번 더 그려서 맞춥니다.
- 포트 8765 는 다른 워커가 쓰고 있어서 검증용 서버는 127.0.0.1:18731 에서 띄웠습니다(`python3 -m http.server 18731 --directory <repo>`).
