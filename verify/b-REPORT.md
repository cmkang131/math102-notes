# v6 위젯 세트 B — 보고서 (브랜치 `v6x-claude-b`)

파일은 `assets/v6-extra-b.js`, `demo-b.html`, `verify/` 세 곳에 있습니다. 기존 파일은 수정하지 않았습니다.
로드 순서는 `<script src="assets/v6.js"></script><script src="assets/v6-extra-b.js"></script>`입니다.
데모에서 위젯 하나만 보려면 `demo-b.html?only=<아이디>`를 엽니다(예: `?only=qf-indef`).

## 실제 API 확인 결과 (지시서 설명과 다른 점)
- `V6.register / makeFn / axes / canvas / title / INK / RED / GRID`는 지시서 설명대로 존재합니다.
- `V6.axes`는 캔버스 전체에 8등분 격자와 0축만 그리고 **눈금 숫자는 그리지 않습니다.** 패널 여러 개와 숫자 라벨이 필요해서, 이 파일 안에 `panel()`(1·2·5 단위 눈금, 숫자 라벨, 클리핑)을 따로 두었습니다. 색은 `V6.INK/RED/GRID`를 그대로 씁니다.
- `makeFn`은 `new Function` 기반이라 `^`를 XOR로 조용히 계산합니다. 그래서 위젯 쪽 `checkExpr`에서 다음을 미리 거부하고 한국어 메시지를 띄웁니다.
  - `^`
  - 허용되지 않은 문자
  - 화이트리스트 밖의 이름(예: `alert`)
  - 문법 오류
- v6.js의 `boot()`는 JSON이 잘못된 config를 **조용히 건너뜁니다.** extra-b가 부팅 뒤에 한 번 더 훑어서, 자기 위젯 이름이면서 JSON이 잘못된 요소에 오류 문구를 넣습니다. v6.js가 extra-b보다 먼저 부팅을 끝낸 경우(늦게 로드된 경우)에도 직접 마운트합니다.
- **현재 레포에서 v6 위젯을 실제로 쓰는 HTML 페이지는 하나도 없습니다**(`grep v6-widget` 결과 0건). 그래서 데모 페이지는 v6.css, v6.js와 hw5 폰트만 불러와서 만들었습니다.
- 레지스트리 이름은 `gd-lr, directional-derivative, quadratic-form, linear-map, dot-product`입니다. v6.js의 `slider-plot, stepthrough`와 겹치지 않고, V6 객체에 새 속성도 노출하지 않습니다(vm 검사로 확인).

## 위젯별 기능과 수학 내용
1. **gd-lr**
   - 1D 프리셋은 세 가지입니다: ½cx², x⁴/4, 사용자 정의 f(f′는 config로 주거나 중심차분).
   - η 세 개를 각 패널에서 곡선 위 경로로 보여 주고, 아래에 f(xₖ)–k 그래프(로그/선형 전환)를 둡니다.
   - 이차함수는 r = 1−ηc로 분류합니다: 단조 수렴 / η=1/c 한 걸음 / 진동 수렴 / η=2/c 왕복 / 발산. 수렴 ⇔ 0<η<2/c를 표시합니다.
   - x⁴/4는 |xₖ₊₁|<|xₖ| ⇔ 0<ηxₖ²<2이고, f″(0)=0이라 오차가 ≈1/√(2ηk)로 줄어든다는 점을 표시합니다(수치 검증함).
   - 사용자 정의 f에는 판정 문구를 붙이지 않고 "해석적 판정 없음"이라고만 씁니다.
   - 2D f=½(x²+κy²)
     - (x,y) 경로를 같은 축척으로 그리고, 해석적 타원 x²+κy²=2f₀ 및 현재 f 높이의 타원을 겹칩니다. 등고선 알고리즘은 쓰지 않습니다.
     - f(xₖ)–k 로그 그래프에 상한 ρ²ᵏf₀를 점선으로 함께 그립니다.
     - 표시 항목: r_x=1−η, r_y=1−ηκ, ρ=max(|r_x|,|r_y|), 수렴 ⇔ η<2/κ, η*=2/(1+κ), ρ*=(κ−1)/(κ+1), 10⁻⁶까지 필요한 k(상한 기준).
     - η는 η* 모드와 s·(2/κ) 수동 모드 중에서 고릅니다.
   - 단계 버튼이 있고, 초기 단계는 `step`, `step2d`로 지정합니다.
2. **directional-derivative**
   - 왼쪽: P를 원점으로 놓고 ∇f, u, 투영 (∇f·u)u, "D_u f=0 방향(등위선 접선)" 점선을 그립니다. 접선은 직선만 그리고 등고선은 그리지 않습니다. |∇f|>3이면 축소해서 그리고 배율을 표시합니다.
   - 오른쪽: D_u f(θ) 사인곡선에 최대 |∇f|(∇f 방향), 최소, 0(접선 방향)을 표시합니다.
   - 정의식 [f(P+hu)−f(P)]/h로 검산합니다.
   - ∇f=0이면 "임계점, 최대 증가 방향 없음"으로 표시합니다.
   - 미분 불가능 판정
     - h와 h/2에서 한쪽 차분의 어긋남이 줄어들지 않으면 "수치적으로 미분불가능해 보임"으로 표시합니다.
     - 그 경우 ∇f 그림을 생략하고, 정의대로 계산한 한쪽 방향미분 그래프를 대신 보여 줍니다.
     - 예: √(x²+y²)는 모든 방향에서 1이고, √|xy|는 f_x=f_y=0인데도 45°에서 1/√2입니다.
   - config의 fx, fy가 f의 수치미분과 다르면 경고합니다. 미분가능성 판정에는 config 값을 쓰지 않습니다.
3. **quadratic-form**
   - λ=((a+c)∓√((a−c)²+4b²))/2를 계산합니다. 상쇄 오차를 피하려고 λ₁=det/λ₂ 형태를 씁니다.
   - 고유벡터 방향은 θ₂=½atan2(2b,a−c)(최댓값 방향)으로 구합니다.
   - 판정은 양/음정부호, 부정부호, 양/음의 준정부호, 영 형식 중 하나입니다. 2계 도함수 판정(a=f_xx, b=f_xy, c=f_yy, D=ac−b²)과 연결해서, D=0이면 판정 불가이고 x⁴+y²(극소)와 x³+y²(극값 아님) 예를 보여 줍니다.
   - 오른쪽 Q(cosθ,sinθ) 그래프에서 min=λ₁, max=λ₂를 표시합니다(Rayleigh). 단위원은 Q의 부호에 따라 색을 칠합니다.
   - b=0이면 "이미 대각", λ₁=λ₂이면 "H=λI, 모든 방향이 고유벡터"라는 문구가 붙습니다.
4. **linear-map**
   - p, q, r, s 슬라이더(±3)와 프리셋(항등, 회전 30°, 전단, x축 반사, 늘이기, 특이)을 제공합니다.
   - 단위 격자의 상, 단위정사각형의 상(평행사변형), Ae₁·Ae₂(=1열·2열), e₁→e₂ 회전 방향 화살표를 그립니다. det<0이면 빨간색 시계 방향으로 바뀝니다.
   - 넓이 막대로 1과 |det|를 비교합니다.
   - det=0이면 "열이 평행 → 직선으로 납작, 역행렬 없음"을, 영행렬이면 "한 점"을 표시합니다.
5. **dot-product**
   - |u|, 각도, |v|, 각도를 슬라이더로 바꾸거나 화살표 끝을 드래그합니다.
   - u·v = u₁v₁+u₂v₂ = |u||v|cosθ, proj_u v, 스칼라 성분, 직교 성분(u와의 내적 0), 직각 표시를 보여 줍니다.
   - 코시–슈바르츠 막대로 |u·v|와 |u||v|를 비교하고 등호 조건(평행)을 표시합니다. 예각/직교/둔각 판정이 붙습니다.
   - u=0이면 proj와 θ는 정의되지 않는다고 표시합니다.

## 한계 / 불확실한 점 (솔직하게)
- **미분가능성 판정은 수치 휴리스틱입니다.**
  - h≈10⁻⁶에서 한쪽 차분의 어긋남이 h를 반으로 줄여도 줄지 않으면 "미분불가능해 보임"으로 판정합니다. 그래서 문구도 단정하지 않습니다.
  - 꺾임이 10⁻⁶보다 가까이 있는 점이나 매우 빠르게 진동하는 함수에서는 틀릴 수 있습니다.
  - 편도함수가 존재하지만 미분 불가능한 경우는 16방향만 검사합니다.
- **중심차분 기울기의 정확도**: 상대오차는 대략 1e-7 수준입니다. |f|가 매우 크면(≈10⁸) 표시값 끝자리에 잡음이 남습니다.
- **gd-lr 사용자 정의 f**: 수치 반복 결과만 보여 주고 수렴 판정은 하지 않습니다. N단계 뒤 값이 작아 보여도 수렴을 보장하지 않습니다.
- **2D GD**: κ는 1~100으로 제한했습니다(κ<1 입력은 1로 올림). "필요한 k"는 상한 ρ²ᵏ 기준이라 충분조건이고 최소값은 아닙니다.
- **문구 출처**: Lax & Terrell 교재 원문과 문구·기호를 대조하지 않았습니다. 표준 정의로 작성했습니다(예: Rayleigh 몫, D=ac−b² 표기).
- **스크린샷 범위**: 800px 폭 데스크톱에서만 확인했습니다. 모바일 폭은 확인하지 않았습니다. 캔버스는 720px 고정 해상도를 축소해서 쓰므로 hi-DPI 화면에서는 글자가 약간 흐릴 수 있습니다.
- **폰트**: hw5/fonts의 Noto Sans KR woff2가 부분집합일 수 있습니다. 위첨자·아래첨자(ₖ, ⁻⁶ 등)는 브라우저 대체 글꼴로 렌더링될 수 있습니다. 폰트 로드 후 한 번 다시 그리도록 해 두었습니다.
- **config 범위 처리**: 슬라이더 범위를 벗어난 config 값은 범위 안으로 잘립니다. 내적 위젯은 벡터 길이가 3을 넘으면 이를 고지합니다. 다른 위젯은 조용히 기본값이나 경계값으로 바꿉니다(예: quadratic-form의 `"a":"abc"` → 기본값).
- **커밋 단위**: 위젯별로 따로 커밋하지 않았습니다. 다섯 개를 함께 작성해서 첫 커밋 하나로 묶었고, 리뷰 수정은 두 번째 커밋입니다.
