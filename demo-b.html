1. gd-lr — 경사하강법 학습률

기본: f = ½·c·x², c = 2, η = 0.1 / 0.45 / 1.05 (2/c = 1 을 넘으면 발산).

같은 설정, 3단계까지만 (cfg.step = 3), 선형 눈금.

비이차: f = x⁴/4 (f″(0) = 0, 수렴 느림 / 초기점에 따라 발산).

사용자 정의: f = log(1 + x*x) (판정 문구 없음, 수치 결과만).

2차원: f = ½(x² + κy²), κ = 10, η = η* = 2/(1+κ).

2차원: κ = 40 — 같은 η* 규칙인데 훨씬 느리고 지그재그가 심함.

2차원: κ = 10, 고정 η = 0.21 > 2/κ = 0.2 → 발산.

2. directional-derivative — 방향도함수

f = x² + 3y², P = (1, 0.5), θ = 30°.

f = sin(x)·cos(y), 편도함수를 config로 제공 (fx, fy), θ = 200°.

∇f = 0 인 점: f = x² + y², P = (0, 0).

미분 불가능한 점: f = sqrt(x*x + y*y), P = (0, 0) — 경고 문구 확인.

편도함수는 있지만 미분 불가능: f = sqrt(abs(x*y)), P = (0, 0) — f_x = f_y = 0 이지만 대각선 방향 한쪽 미분은 1/√2.

config 편도함수에 오타 (fy = 3*y, 실제는 6*y): 경고만 내고 미분가능성 판정은 f 자체로.

|∇f| 가 큰 경우 (축소 표시): f = 5*x*y + y*y*y, P = (1, 1).

3. quadratic-form — 이차형식

양정부호: a = 2, b = 0.6, c = 1.

부정부호(안장): a = 1, b = 2, c = 1.

준정부호: a = b = c = 1 (λ₁ = 0).

중근: a = c = 1.5, b = 0.

음정부호, b = 0: a = −2, b = 0, c = −0.5.

4. linear-map — 2×2 행렬과 행렬식

기본 행렬 [[1, 0.5], [0.3, 1]].

회전 30°.

전단 [[1, 1], [0, 1]].

반사 [[1, 0], [0, −1]] (det = −1, 방향 반전).

특이행렬 [[1, 2], [0.5, 1]] (det = 0).

det < 0 일반: [[0.5, 1.5], [1.2, −0.4]].

5. dot-product — 내적과 정사영

예각: |u| = 2.5 (15°), |v| = 2 (65°).

둔각: u = (2, 0.5), v = (−1.5, 1.5).

직교: u = (2, 1), v = (−1, 2).

u = 0.
